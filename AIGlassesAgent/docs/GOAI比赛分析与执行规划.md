## 2. 产品方案：出行辅助 Agent（推荐主推）

> 选择理由：AI+眼镜 个性化评审只认「第一视角 + 随身 + 轻量反馈」。出行辅助同时命中三点，且 Demo 画面感最强（实时翻译字幕、视野导航、看物问答），任务闭环清晰，最容易让评委 30 秒内看懂价值。若你想换方向（如工作效率/学习陪伴），§2–§3 可整体替换，框架不变。

### 2.1 目标用户与核心痛点
- **目标用户**：经常出境/跨城出行者、商务差旅、自由行游客、以及不熟悉周边环境的通勤者。
- **核心痛点**：
  1. 异国/异地语言不通（路牌、菜单、对话）。
  2. 走路导航还要看手机，不安全也不便。
  3. 看到陌生事物想立刻知道是什么（展品、植物、建筑、商品）。
  4. 行程/忌口/偏好散落各处，缺少随身、记得住的助手。

### 2.2 「为什么必须在眼镜上」（眼镜原生性论证 —— 评审命门）
| 能力 | 手机/网页做法 | 眼镜做法（我们的差异化） |
|---|---|---|
| 翻译 | 拍照→打开 App→等结果 | 第一视角看到即译，字幕直接叠加视野 |
| 导航 | 低头看屏幕 | 语音唤醒 + 视野箭头/提示，免手免低头 |
| 看物问答 | 掏手机拍、切应用 | 看到即问，VLM 理解眼前画面 |
| 随身记忆 | 手动记备忘录 | 语音说一句即记住偏好/忌口，下次主动提醒 |

> 所有功能都围绕「**第一视角感知 + 语音免手 + 视野轻量反馈**」，无法在手机上等价实现 → 满足原生性要求。

### 2.3 任务闭环设计（示例：异国餐厅点餐）
1. **任务输入**：用户第一视角看到外文菜单 + 语音「这菜单上推荐什么？我有坚果过敏提醒下」。
2. **意图理解**：识别「菜单 OCR 翻译 + 菜品推荐 + 过敏风险提示」。
3. **任务规划**：截帧 → VLM 识别文字 → 翻译 → 结合用户忌口/偏好 → 生成推荐。
4. **能力调用**：摄像头截帧 → VLM(视觉理解) → 翻译工具 → 用户知识库(忌口/偏好 RAG)。
5. **结果交付**：视野字幕显示「翻译 + 推荐菜 + ⚠坚果警告」。
6. **验证**：样例输入输出 + 截图留存。
7. **安全边界**：翻译/推荐仅供参考，过敏等关键项须用户最终确认。
8. **记忆**：记住用户忌口/偏好，后续场景主动调用。

### 2.4 三个可演示场景（初赛 Demo 脚本，各 30–60s）
1. **实时翻译**：看到外文路牌/菜单 → 视野字幕即时翻译。
2. **导航提示**：语音「带我去最近的地铁站」 → 视野箭头 + 语音播报。
3. **看物问答**：看到展品/商品 → 「这是什么」 → VLM 回答并附来源。

## 3. 技术方案（出行辅助落地版）

### 3.1 Agent 架构（分层）
- **入口层**：眼镜端模拟器第一视角 UI + 手机/Web 对照面板（展示后台推理）。
- **感知层**：ASR（语音输入）+ 摄像头截帧 + VLM（视觉理解/ OCR）。
- **编排层**：Agent 主控（LangGraph）—— 意图路由 + 任务规划 + 工具调度 + 状态/记忆管理。
- **能力层（工具）**：翻译 API、地图/导航 API、搜索工具、用户知识库（RAG）。
- **输出层**：TTS 语音播报 + 视野字幕/卡片（轻量反馈）。
- **记忆层**：用户偏好/忌口/历史行程（向量库 + 结构化存储）。

### 3.2 技术栈（已确认：Python + 开源 Agent 框架）
- **语言/运行时**：Python 3.12（本机已配好隔离 venv 环境）。
- **Agent 框架**：LangGraph（可控、易讲清规划与工具调用；备选 AutoGen）。
- **多模态**：视觉 VLM（Qwen-VL / Gemini）、ASR（FunASR / Whisper）、TTS（Edge-TTS）。
- **工具**：翻译 API、地图/导航 API、搜索；知识库用轻量 RAG（如 Chroma + 向量模型）。
- **演示形态**：手机第一视角录屏模拟眼镜（叠加字幕 UI），或 Rokid 模拟器；旁白讲解链路。

### 3.3 合规边界（AI 眼镜必写）
- 录音录像、环境识别须声明**授权范围与使用边界**，仅用于本地辅助、不上传敏感画面。
- 个人数据最小化、可删除机制（用户可清除记忆层）。
- 不替代专业判断：翻译/导航/推荐仅供参考，不做自动驾驶或医疗决策。

## 5. 风险与建议
1. **时间极紧**：初赛仅 11 天，优先「能讲清的闭环 + 可看 Demo」，别追求技术完美。
2. **眼镜原生性是命门**：任何手机/网页能做的，都要回答「为什么必须在眼镜上」。
3. **合规先行**：AI 眼镜涉及录音录像+环境识别，材料里必须写清授权与边界，否则重扣。
4. **别替代专业决策**：出行只做辅助提示，不做驾驶控制/高风险操作。
5. **闭环 > 功能堆砌**：一条跑得通的完整链路，胜过十个半成品功能。
