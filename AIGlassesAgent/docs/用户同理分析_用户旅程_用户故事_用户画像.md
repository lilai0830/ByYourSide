# 用户研究：用户画像 · 用户旅程 · 用户故事

> 项目：GOAI 无界应用 · AI+眼镜 · 出行辅助 Agent
> 用途：初赛 PPT「行业场景价值（25%）」与 Demo 脚本的设计底座
> 版本：v1.2 ｜ 2026-08-06
> 关联文档：《市场调研_AI眼镜竞品分析与MarketGap.md》（下称「调研」）、《GOAI比赛分析与执行规划.md》（下称「规划」）

---

## 0. 研究范围与诚实性声明（先读）

本研究直接服务于已锁定的设计决策：

- **三个 Demo 场景（红海标配）**：实时翻译 / 视野导航 / 看物问答
- **三个研究目标**：O1 第一视角长期记忆、O2 分级主动与"抑制"、O3 带宽感知输出编排（见调研 §10）。隐私按比赛合规要求作边界声明，不做功能化目标或卖点。

**出处与可信度约定**（沿用调研 §6 的档位，确保对外材料不把推断冒充足用户反馈）：

- `【已证实】`：痛点/现状有调研 §5、§9 来源（官方/机构/媒体/UGC）支撑。
- `【已证实·强】`：机构或多家媒体交叉印证（如 G8 垂直人群：深圳 39 家需求清单 + Rokid 无障碍）。
- `【团队假设】`：主要来自竞争格局的设计性推断，市场暂无明确需求喊声。**O3 相关的画像诉求/用户故事均为本假设，评审时须如实标注。**

> ⚠️ 三项明确共识：① 三场景是"载体"不是"增量"，差异化靠 O1–O3 加成（调研 §8）；② O3 是跳出红海的主要创新杠杆但属假设（调研 §10.1）；③ 隐私按比赛要求作合规边界声明，不渲染为功能亮点。

## 1. 用户画像（Personas）

> 设计原则：画像必须能映射到具体的研究目标与场景，否则只是"虚构人物卡"。
> 共 **3 个主用户**。被摄者不单列画像——隐私按要求作比赛合规边界声明，不做功能化目标。

### 1.1 主画像 A — 「跨境商务客」林越

| 维度 | 内容 |
|---|---|
| 代号 | 林越 / 33 岁 / 管理咨询顾问 |
| 出行画像 | 月均 1–2 次出境，会议密集，常在陌生城市连轴转；商务社交多、对"在场得体"敏感 |
| 一句话目标 | "在异国会议与饭局里，不卡壳、不失礼、还能记住关键的人与细节。" |
| 高频场景 | 实时翻译（会议/菜单）、看物问答（识人/识物）、记忆（忌口/偏好/行程） |
| 未满足需求 | ① 会议中不能看手机（社交失礼）却要读翻译 → `【已证实】`语音在嘈杂环境识别率<30%、室外听不清（调研 §3.1/§5.2）；② 记不住新联系人"上次见过的人叫什么/聊过什么" → `【已证实痛点】`UGC"无个人上下文"（调研 §5.3）；③ 忌口/偏好每次都要重说（坚果过敏） |
| 映射到研究目标 | **O1**（认人/停车/上次点单记忆）、**O3**（会议中禁言只字幕/角标，团队假设）、**G9**（不确定术语标注） |
| HUD 反馈偏好 | 会议/社交：静默 + 视野角标，绝不语音；步行独处：语音 + 字幕 |
| 出处 | 目标用户定义见规划 §2.1；痛点来自调研 §3.1、§5.2、§5.3 |

### 1.2 主画像 B — 「自由行探索者」苏晴

| 维度 | 内容 |
|---|---|
| 代号 | 苏晴 / 26 岁 / 自由摄影师·内容创作者 |
| 出行画像 | 出境自由行，边走边拍、看展看物、陌生城市靠导航；内容创作常需即时查资料 |
| 一句话目标 | "走到哪拍到哪、问到哪，路上还安全、不卡壳。" |
| 高频场景 | 视野导航（步行/骑行）、实时翻译（路牌/菜单）、看物问答（展品/商品）、记忆（看物关联） |
| 未满足需求 | ① 走路看手机导航易撞人、不安全 → `【已证实】`规划 §2.1 痛点2；② 展品讲解"千篇一律的通用废话" → `【已证实】`调研 §5.3；③ 骑行时语音导航既不安全又失礼；④ 重复问同类事物、记忆散落 |
| 映射到研究目标 | **O2**（导航"走错才说"、骑行禁言）、**O3**（步行vs骑行不同输出形态，团队假设）、**O1**（看物记忆关联） |
| HUD 反馈偏好 | 步行：箭头 + 简短语音；骑行：纯震动 + 视野箭头，零语音；看物：字幕 + 角标 |
| 出处 | 目标用户定义见规划 §2.1；痛点来自调研 §5.3 |

### 1.3 主画像 C — 「异地新市民」老周

| 维度 | 内容 |
|---|---|
| 代号 | 老周 / 44 岁 / 外派工程师（新城市半年） |
| 出行画像 | 每日骑车通勤，不熟悉周边，停车后常找不到车；重复问同类问题 |
| 一句话目标 | "戴上一副记得路、记得车、又不啰嗦的眼镜。" |
| 高频场景 | 视野导航（通勤/骑行）、记忆（停车位置/常去地点）、分级主动 |
| 未满足需求 | ① 骑车不能看手机、新城市找路难 → `【已证实】`规划 §2.1 痛点2；② 停车后找不到车/记不住常去地 → `【已证实痛点】`O1 回溯问题"车停哪层了"（调研 §10.2）；③ 重复问同样问题、记忆散落 → `【已证实】`调研 §5.3 |
| 映射到研究目标 | **O2**（骑行禁言只震动、场景禁言）、**O1**（停车/常去地记忆）、**O3**（运动场景只震动/箭头，团队假设） |
| HUD 反馈偏好 | 骑行：震动 + 箭头，全程静音；到熟悉路口：可静默只角标 |
| 出处 | 目标用户定义见规划 §2.1；痛点来自调研 §5.3、§10.2 |

> 画像小结：A/B/C 覆盖规划 §2.1 的全部目标用户段，且每人都能"算"到 O1–O3 中的 2–3 个。O3（带宽编排）在 A/B/C 中的"反馈偏好"均标注为团队假设，未伪称为用户原话需求。隐私按比赛合规要求作边界声明，不进入任何画像的功能诉求。

## 2. 用户旅程（User Journey）

> 主线：**林越的境外出差一天**——一条端到端旅程，串联三场景与 O1–O3，证明"差异化不在单点功能，而在 Gap 加成"。
> 另附**苏晴的骑行导航半日**（聚焦 O2/O3/O1），避免单一画像撑不起高频通勤场景。

### 2.1 旅程地图：林越 · 境外出差一天

| 阶段 | 用户目标 | 行为 | 痛点（无 Agent） | Agent 加持（场景 + Gap） | 情绪（前→后） | 对应目标 |
|---|---|---|---|---|---|---|
| ① 行前 | 调取上次出差记忆 | 语音"上次东京住哪、忌口记一下" | 记忆散落各处，重找 | **O1** 调入上次行程/酒店/忌口，生成今日简报角标 | 焦虑→安心 | O1 |
| ② 机场/通关 | 与工作人员对话 | 看护照/问答，环境嘈杂 | 语音识别率<30%、听不清 `【已证实】` | **实时翻译**：视野字幕即时译；**O3** 人群中只字幕不语音（假设） | 紧张→顺畅 | O3+翻译 |
| ③ 异国街头 | 走到目的地 | 边走边看手机导航 | 低头看屏不安全、易走错 | **视野导航**：箭头+简短语音；**O2**"走错/将错过才出声"；**O3** 步行用箭头+短语音（假设） | 烦躁→轻松 | O2+O3+导航 |
| ④ 餐厅点餐 | 读懂菜单、避雷 | 看外文菜单，提过敏 | 菜单看不懂、忌口每次重说 | **实时翻译+OCR**；**O1** 调出坚果过敏；**G9** 专业术语标"需确认" | 不安→信任 | O1+G9+翻译 |
| ⑤ 会议/社交 | 得体社交、记住人 | 见合作方，需记名字话题 | 记不住"上次见过的人"、看手机失礼 | **O1** 认出"上次见过的人"+上次话题提示；**O2/O3** 会议中静默只角标（假设） | 局促→从容 | O1+O2+O3 |
| ⑥ 回程与记忆沉淀 | 沉淀今日记忆、不被打扰 | 通勤/睡前，眼镜以静默角标汇总今日要点 | 记忆散落，明天又从零开始 | **O1** 汇总今日记忆（认识的人/忌口/去过地）；**O2** 静默只角标不打扰；**O3** 用角标而非语音（假设） | 充实→延续 | O1+O2+O3 |

**情绪曲线（定性）**：①低→②中→③先降后升（走错前紧张、被提醒后松）→④升→⑤升→⑥收尾于"记忆延续"的高点。
**Moment of Truth（差异化瞬间）**：③的"你走错我才说" + ⑤的"开会它一声不吭只给你角标"。这两处正是红海产品（全程靠唤醒词、或乱打扰）做不到、而 O2/O3 直接命中的点。

### 2.2 旅程地图（附）：苏晴 · 骑行导航半日

| 阶段 | 用户目标 | Agent 加持（O2/O3/O1） | 对应目标 |
|---|---|---|---|
| 设目的地 | 出发前定好路线 | 语音设 destination，角标静默确认 | O3 |
| 骑行中 | 不迷路、不危险 | **O2** 骑行禁言只震动+视野箭头；**O3** 运动场景纯震动不语音（假设） | O2+O3 |
| 路口将走错 | 纠偏 | **O2** "将错过才震动提醒"，不打断 | O2 |
| 看到展品 | 即时问答+记忆 | **O1** 看物关联"你上次问过这家店" | O1 |
| 收尾 | 不打扰 | **O2** 静默角标，不抢话 | O2+O3 |

> 说明：苏晴旅程覆盖 O2（分级主动/骑行禁言）+ O3（带宽编排，运动场景纯震动）+ O1（看物记忆关联），不涉及隐私功能化。

## 3. 用户故事（User Stories）

> 格式：`作为<画像>，我希望<能力>，以便<收益>`。
> 优先级：MoSCoW（Must/Should/Could/Won't-now）。`★` 标注出处档位。
> 凡涉及 O3 的故事均标 `【团队假设】`——描述我们**提议**的能力，经 Demo 验证而非市场喊声。

### Epic 1 · 实时翻译（标配载体 + O3/G9 加成）

- **US-T1（Must）** 作为跨境客，我希望看到外文菜单/路牌即时叠加翻译字幕，以便无需掏手机也能读懂。★`【已证实】`规划 §2.1 痛点1
- **US-T2（Should）** 作为用户，我希望翻译是"归纳式"而非逐句直译（一句话总结要点），以便在嘈杂街道不被长句淹没。★`【团队假设】`O3 差异化
- **US-T3（Should）** 作为用户，我希望专业/不确定术语被标注"需确认"，以便不误信错译。★`【已证实】`G9 置信度（调研 §6）

### Epic 2 · 视野导航（标配载体 + O2/O3 加成）

- **US-N1（Must）** 作为步行者，我希望视野内箭头+简短语音指引，以便不用低头看手机。★`【已证实】`规划 §2.1 痛点2
- **US-N2（Must）** 作为用户，我希望只有"我走错/将错过"时才主动出声，以便不被频繁打断。★`【已证实痛点+团队方案】`O2（调研 §6 G3）
- **US-N3（Should）** 作为骑行者，我希望导航只用震动+视野箭头、完全静音，以便安全且不失礼。★`【已证实痛点】`+`【团队假设】`O2+O3 场景模式

### Epic 3 · 看物问答（标配载体 + O1/G2 加成）

- **US-V1（Must）** 作为游客，我希望看到展品/商品即时问答并附来源，以便快速获取可信信息。★`【已证实】`规划 §2.1 痛点3
- **US-V2（Should）** 作为用户，我希望这次问过的事物下次主动关联（如"你上次问过这家店"），以便记忆延续。★`【已证实痛点+团队形态】`O1（调研 §6 G4）
- **US-V3（Could）** 作为用户，我希望识别到商品后能比价/提醒，以便从"知道"到"办完"。★`【已证实】`G2 办事闭环（规划 §2.3 链路）

### Epic 4 · 第一视角长期记忆（O1）

- **US-M1（Must）** 作为用户，我希望问"车停哪层了/上次点单是什么"能得到答案，以便随身记忆替代备忘录。★`【已证实痛点+团队形态】`O1
- **US-M2（Should）** 作为商务客，我希望眼镜认出"上次见过的人"并提示上次话题，以便在社交中不尴尬。★`【已证实痛点】`O1
- **US-M3（Must）** 作为用户，我希望记忆可导出/可一键清除，以便数据自主可控（可清除亦为比赛合规要求，规划 §3.3）。★`【已证实痛点+团队形态】`O1

### Epic 5 · 分级主动与"抑制"（O2）

- **US-P1（Must）** 作为会议中的用户，我希望眼镜保持静默只显示角标，以便不干扰在场他人。★`【已证实痛点+团队方案】`O2
- **US-P2（Should）** 作为用户，我希望有"打扰预算"（每小时最多提示 N 次），以便关键时刻才被打断。★`【团队方案】`O2
- **US-P3（Should）** 作为交谈中的用户，我希望 Agent 检测我在与人说话时自动禁言，以便不抢话。★`【团队方案】`O2

### Epic 6 · 带宽感知输出编排（O3，团队假设）

- **US-O1（Should）** 作为用户，我希望同一答案按我当前状态自动选字幕/语音/图标/震动，以便信息量匹配场景。★`【团队假设】`O3
- **US-O2（Should）** 作为用户，我希望 LLM 输出被压到≤N字+≤1动作，以便 HUD 不堆积。★`【团队假设】`O3

> 评审提示：Epic 6 两条故事是本项目跳出红海三场景的**创新杠杆**，但属假设。对外材料须写"我们提议并验证于 Demo"，不得写"用户强烈要求"。

> 隐私相关需求（如数据可清除）作为**比赛合规边界要求**，并入 O1 的记忆可控性，不独立成 Epic/卖点。

## 5. 给下一步的衔接建议

1. **Demo 脚本**：优先跑通 ②→③→④→⑥（翻译→导航→点餐→记忆沉淀），一条链路覆盖 O1/O2/O3 与三场景，30–60s 可讲清。
2. **PPT 叙事**：用 §2.1 旅程的"Moment of Truth"作价值页钩子；用 §4 矩阵作差异化页证据。
3. **诚实性**：所有对外材料对 O3 统一措辞"团队创新假设，经 Demo 验证"；隐私按比赛要求作合规边界声明，不渲染为功能亮点。
4. **不做**：不新增第 4 个 Demo 场景（聚焦三场景+三目标，调研 §10.4 已排除 G5/G7/G8/G9/G10）。
