## 0. 一句话结论

**硬件正在快速收敛（都是 AR1 芯片 + 12MP 摄像头 + 波导 + 语音助手），软件侧的"Agent 化"才刚开始起跑；行业最大的空白不在"能不能看懂"，而在"看懂之后能不能替你办完、什么时候该说话、以及被拍的人怎么办"。**

三个可量化的行业现状：
- 出货高增长：2025 全球智能眼镜出货 **1450.5 万台，同比 +41.6%**，Meta 独占 **73%~85%** 份额 `[机构]`
- 体验塌方：主流渠道平均**退货率 30%~50%**，抖音渠道一度达 60% `[媒体/UGC]`
- 同质化：第一视角拍摄 + 实时翻译 + 语音问答已是"标配三件套"，差异只剩 AI 与支付 `[媒体]`

| 路线 | 代表产品 | 核心逻辑 | 交互重心 | 商业天花板 |
|---|---|---|---|---|

| **C. AI+AR 显示眼镜** | Meta Ray-Ban Display、Rokid Glasses、雷鸟 X3 Pro、千问 S1、Even G2 | 视野内轻量信息层 + 空间交互 | 语音 + 触控 + 手势/腕带/戒指/眼动 | 被寄予"下一代终端"厚望，占比约 29.8% |

> **路线分歧的本质**（值得记住的一句行业原话）：
> Meta 是"先做一副时尚社交眼镜，再加 AI"；Rokid/千问是"先为 AI 设计一套系统，外形恰好长成眼镜"。前者争品牌与销量，后者争**交互标准与生态定义权**。`[媒体]`

### 3.1 关键判读

1. **语音仍是唯一"全行业通用"入口，但已被证明不够用**：嘈杂环境识别率跌至 30% 以下、平均唤醒响应约 2 秒、室外听不清播报 `[媒体/UGC]`。
2. **"瞳孔/眼动"是 2026 年才刚被点亮的新维度**——目前**只有千问智能体眼镜在消费级 AI 眼镜上正式落地**（视线即指令 + 注意力判断 + 虹膜核身 + 疲劳检测）。这意味着眼动交互的产品化经验、交互范式、可用性边界**几乎是空白地带**。
3. **手势交互出现路线分裂**：Meta 走"离开眼镜"的 sEMG 腕带（隐蔽、静音、可空中书写）；国内走"手表/戒指/触控板"的低成本外设路线；**摄像头识别的空中手势几乎无人主推**（功耗、误触、社交尴尬）。
4. **交互创新集中在"输入"，输出侧几乎没有创新**：无屏产品只有语音一条输出通道，带屏产品基本是把手机卡片搬到镜片上。**这是最被忽视的一环。**

### 4.1 判读：行业 Agent 化处于什么阶段？

```
阶段0 语音助手      → 阶段1 多模态问答      → 阶段2 工具调用      → 阶段3 主动智能体
（Hey Siri 式）        （看一眼告诉你是什么）    （帮你下单/导航/支付）  （知道何时该做、何时闭嘴）
   小米/华为音频         Meta / 雷鸟 / 小米       Rokid / 千问 / 华为      千问在喊，无人做成
   ────────────────────── 行业主体在这里 ──────────────────────┤
```

**结论：整个行业停在"阶段 2 的门口"。"看到什么→说出来"已经做烂了，"看到什么→替你办完→并且知道什么时候不该说话"几乎没有成熟产品。**

## 5. 现有产品的真实痛点清单

### 5.1 硬件层（我们改不了，但要绕开）

| 痛点 | 具体表现 | 证据 |
|---|---|---|
| 重量 | 主流 36~51g，是普通眼镜（~20g）的 2 倍；戴 1 小时鼻梁压红 | 消委会比较试验 `[机构]` + 多篇实测 `[UGC]` |
| 续航 | 官标与实测差距大；开语音唤醒实测 2h；带屏产品普遍 2.5~5h；雷鸟 X3 Pro 重度 20 分钟 | `[UGC]` |
| 发热 | 高强度使用镜腿后部发热 | `[媒体]` |
| 端侧算力 | 90% 功能依赖手机/云，**断网即失效** | `[媒体]` |

### 5.2 交互层（**Agent 可以直接改善**）

| 痛点 | 具体表现 |
|---|---|
| 唤醒慢 | 平均 2 秒响应，嘈杂环境识别率 <30% |
| 不支持连续对话 | "雷鸟 X3 Pro 对话慢，不支持连续对话" `[UGC]` |
| 输出通道单一 | 无屏产品只能语音播报，复杂信息（多路线对比）效率极低；室外听不清 |
| 反馈缺失 | 下指令后陷入"尬等"，无法感知 AI 在干嘛 |
| 交互割裂 | "APP 对话框回答了，耳机却没有声音" `[UGC]` |

### 5.3 智能层（**核心机会所在**）

| 痛点 | 具体表现 |
|---|---|
| 视觉理解粗糙 | 问一杯拿铁答"这是一个杯子"；问黑色卫衣穿搭答"这件蓝色的不错" `[UGC]` |
| 会议纪要抓不住重点 | 记下"今天天气不错""大家辛苦了"，真正的数据一个没记 `[UGC]` |
| 场景理解不可用 | 卡路里识别准确率不足 60%；环境分析生成的建议是"通用废话" `[媒体]` |
| 翻译在混合语种下崩 | 中英混杂错误率飙升，延迟 >1s 打断对话节奏 `[媒体]` |
| 无个人上下文 | 不记得你的偏好、忌口、日程、上次说过的话 |

### 5.4 信任层（**评分红线，也是差异化机会**）

| 痛点 | 具体表现 |
|---|---|
| 被摄者零知情权 | 户外强光下 LED 3 米外看不见；胶带一贴照拍不误；音频录制 15s 不亮灯 `[媒体]` |
| 无追溯机制 | 用户无法回答"这副眼镜今天采了什么、传了什么、存了多久" |
| App 安全差 | 15 款样品中 **13 款配套 App 存在可被篡改/二次打包漏洞** `[机构]` |
| 无置信度表达 | AI 从不说"我不确定"，错误答案与正确答案语气一致 |

### 5.5 生态层

- **严重同质化**：拍摄 + 翻译 + 语音问答 = 标配，差异只剩品牌和支付。vivo 已因同质化叫停 AI 眼镜项目 `[媒体]`
- **缺乏"非它不可"的场景**：多数功能可被手机替代
- **生态割裂**：华为 AI 眼镜在非鸿蒙手机上只是"带摄像头但不能拍照的蓝牙耳机" `[官方]`

## 6. Market Gap 分析 ⭐⭐

> 筛选原则：**① 纯软件/Agent 层可实现（不需要新硬件）② 眼镜原生（手机做不到或体验劣化）③ 当前无成熟产品占位。**

> **⚠️ 出处标注（重要，评审前必读）**：下列 10 个 Gap **并非全部是"市场原话"**。为诚实区分"市场真实声音"与"团队推断"，每个 Gap 标注可信档位：
> - **【已证实】**：痛点/现状有 §9 来源（官方/机构/媒体/UGC）支撑；
> - **【已证实·强】**：有机构或多家媒体交叉印证，证据最硬；
> - **【已证实痛点 + 团队方案】**：真实痛点存在，但"怎么做"是本团队的设计推断；
> - **【团队洞察·假设】**：主要基于竞争格局的**设计性推断**，市场暂无明确需求喊声，属待验证假设，**对外材料不得冒充足用户反馈**。

| Gap | 档位 | 一句话出处 |
|---|---|---|

### Gap 1｜输出侧的"信息编排层"完全缺位 ★★★★★  【团队洞察·假设】

- **现状**：行业把 100% 精力放在输入创新（腕带/眼动/戒指），输出侧要么是一条语音，要么是把手机卡片硬搬进镜片。
- **本质**：眼镜的**输出带宽是所有终端里最窄的**（1 行字幕 / 3 秒语音 / 1 次震动），但没人为这个带宽重新设计 LLM 的输出协议。
- **Agent 能做**：一个「带宽感知的渲染器」——同一个答案，根据用户当前是走路/开会/骑车/独处，自动决定用**语音 / 字幕 / 图标 / 震动 / 干脆不说**，并把 LLM 输出强约束为 ≤20 字 + ≤1 个可执行动作。
- **可 Demo 性**：极高，模拟器上直接可视化"同一问题在四种场景下的四种回答形态"。

### Gap 2｜"问答"到"办事"的最后一公里 ★★★★★  【已证实】

- **现状**：几乎所有产品止步于"看一眼→告诉你是什么"。Rokid 智能体商店与千问 Skill 刚起步，且多是"垂类问答专家"而非"任务执行体"。
- **Agent 能做**：完整闭环 = 意图理解 → 任务规划 → 多工具调用 → 结果交付 → **用户确认 → 记忆沉淀**。
  例：看到一张会议海报 → 自动识别时间地点 → 查日程冲突 → 建日程 → 设出发提醒 → 到点推导航。全程无需掏手机。
- **为什么必须在眼镜上**：触发点是"眼睛看到的东西"，掏手机拍照+切 App 会让这个链路彻底不成立。

### Gap 3｜主动性的真正难题是"抑制"，无人解决 ★★★★★  【已证实痛点 + 团队方案】

- **现状**：90% 产品必须唤醒词才动。千问是唯一提出主动服务的，但官方也承认"对没有足够理解的用户不具备主动服务条件"——**说明连领跑者也没解决"什么时候该开口"。**
- **行业盲区**：所有人都在做"感知得更多"，没人做"**打扰得更少**"。而 AI 眼镜挂在脸上，一次错误的主动打扰造成的反感是手机 Push 的 10 倍。
- **Agent 能做**：分级主动机制 —— `静默记录 → 视野角标（不出声）→ 轻震动 → 语音询问 → 直接执行`，配合「打扰预算」（每小时最多 N 次）与「场景禁言」（开会/驾驶/交谈中）。
- **差异化价值**：这是一个**很难被硬件抄走**的软件能力，且直接对应比赛的"交互自然"评分项。

### Gap 4｜第一视角长期记忆（第二大脑）★★★★★  【已证实痛点 + 团队形态】

- **现状**：产品各自录像录音，但**不构成可检索的个人记忆**。会议纪要抓不住重点就是这个问题的症状。
- **Agent 能做**：把第一视角流转成结构化事件记忆（who / what / where / when + 视觉锚点 + 用户当时的语音标注），支持自然语言检索：
  - "我把车停在哪一层了？" / "上周见的那个人叫什么？" / "上次来这家店我点的什么？" / "我今天吃药了吗？"
- **眼镜原生性拉满**：手机不可能全天记录第一视角；这是眼镜**唯一无法被替代**的能力。
- **注意**：必须配套隐私设计（隐私边界按比赛合规要求处理），否则是红线。

### Gap 5｜端云路由与优雅降级 ★★★☆☆  【已证实】

- **现状**：90% 功能依赖云，断网即废；延迟 >1s 打断对话节奏。
- **Agent 能做**：分级路由层 —— 端侧小模型负责唤醒判定/意图分类/隐私过滤/兜底应答，云端负责重推理；断网时明确降级而不是静默失败。
- **加分点**：Demo 里把"这一次请求走了哪条路径、为什么"可视化出来，直接命中"技术实现深度 + 可追溯"。

### Gap 6｜隐私是被"合规文档化"了，而不是被"产品化" ★★★★☆  【已证实(合规脆弱) + 团队洞察】

- **现状**：所有厂商的隐私方案 = 一颗 LED + 一段用户协议。而 LED 户外看不见、可被胶带遮挡、音频录制可不亮灯；**被拍摄者完全没有任何权利界面**。
- **行业空白**：没有任何一款产品服务于"**镜头对面的人**"。
- **Agent 能做**（三个都是软件层）：
  1. **端侧即时脱敏**：陌生人脸/车牌/证件/屏幕内容在数据离开设备前自动打码；
  2. **隐私地理围栏**：卫生间/更衣室/医院/学校等区域自动禁摄并给出明确提示；
  3. **可验证采集日志**：一份用户可导出、可审计、可一键清除的"今天采了什么"清单。
- **合规说明**：安全/合规占 10% 权重，AI 眼镜赛道**明确要求材料中说明隐私边界**，本项目按比赛要求作合规边界声明。

### Gap 7｜眼镜作为"现实世界的触发器"去调度其他设备 ★★★★☆  【已证实 + 团队推演】

- **现状**：行业共识是"眼镜是手机配件"。反向的"**眼镜当 Agent 的眼睛和手，去调度手机/电脑/家居/车**"只有 Rokid 智能体商店做了皮毛（特斯拉车控、智能家居）。
- **Agent 能做**：眼镜只负责"感知 + 确认 + 轻反馈"，重执行全部下放到手机/云端 Agent，结果回到视野。这同时绕开了端侧算力和续航的硬件短板——**把硬件劣势变成架构选择**。

### Gap 8｜被忽略的高价值垂直人群 ★★★★☆  【已证实·强】

| 人群 | 规模/需求 | 当前供给 | 空白点 |
|---|---|---|---|
| 视障/听障 | 全国 2 亿视障 + 3000 万听障 | **仅 Rokid 组建了专门的无障碍团队** | 障碍识别、无障碍阅读、实时字幕，个性化程度低 |
| 认知障碍/独居老人 | 提醒吃药、认人、防走失、跌倒 | 基本空白 | 眼镜是"必须随身 + 第一视角"的唯一合适载体 |
| 一线巡检/护理/执法 | 深圳发布的《AI 眼镜场景需求清单》：39 家需求单位提出大量真实痛点，医疗领域最密集 | 34 家供给方，多为通用方案 | **需求已被政府主动列表化，供给却是通用货** |
| 神经多样性/社交辅助 | 社交提示、情绪线索 | 仅 Even G2 的 Conversate 是雏形 | 几乎无人做 |

### Gap 9｜AI 的"诚实度"与可追溯性 ★★★☆☆  【已证实·数值待核】

- **现状**：卡路里识别 <60% 准确率，但 AI 从不说"我不确定"；错误答案和正确答案用同样自信的语气播报。这是退货率的重要贡献者。
- **Agent 能做**：置信度分级表达（确定 / 可能 / 需要你确认）+ 关键信息（过敏源、药品、金额、方向）强制二次确认 + 答案来源可溯。
- **比赛价值**：直接命中"不替代专业判断"的红线要求，把合规变成体验。

### Gap 10｜场景模式识别（Context Mode）★★★☆☆  【团队洞察·假设】

- **现状**：一套交互走天下。开会、骑车、独处、社交、购物的需求完全不同，但没有产品自动切换交互策略。
- **Agent 能做**：场景分类器 → 动态调整（唤醒灵敏度 / 输出通道 / 打扰阈值 / 隐私等级 / 可用工具集）。这是 Gap 1 与 Gap 3 的公共底座。

## 8. 对现有方案（出行辅助 Agent）的对标结论

**坏消息**：现有规划的三个 Demo 场景——实时翻译、视野导航、看物问答——**恰好是当前市面上同质化最严重的"标配三件套"**。Rokid 支持 89 语种、雷鸟接入高德 AR 导航、华为覆盖 5000+ 景点讲解，都是成熟商用功能。单纯复现会被评委判为"没有增量"。

**好消息**：这三个场景可以作为**载体**，把上面的 Gap 装进去而不是替换掉：

| 原场景 | 加上 Gap 后的差异化 |
|---|---|
| 实时翻译 | + G1 输出编排（"归纳式翻译"而非逐句直译）+ G9 置信度（专业术语标注不确定） |
| 视野导航 | + G3 分级主动（不是你问才说，而是判断你走错时才出声）+ G10 场景模式（骑行时禁语音只震动） |
| 看物问答 | + G4 记忆沉淀（这次问过的，下次主动关联）+ G2 任务闭环（识别→比价→下单→提醒取货） |

> **一句话建议**：不要比"能不能翻译"，要比"**翻译完之后你还记得、还会用、还知道什么时候不该翻译**"。

### 10.2 逐项目标定义（研究问题 + 成功判据）

**O1 第一视角长期记忆**
- **研究问题**：如何把第一视角流（画面锚点 + 语音 + 位置 + 时间）沉淀为结构化、可检索的个人记忆，支持自然语言回溯（"车停哪层了""上次来这家店点了啥"）？
- **成功判据**：Demo 内能对一个第一视角片段抽取 `who/what/where/when + 视觉锚点`，准确回答 ≥3 个回溯性问题；记忆可导出/清除（合规边界须可清除，见规划 §3.3）。
- **出处**：痛点真实——UGC"无个人上下文/会议笔记抓不住重点"、千问健康记忆画像（官方）；"第二大脑"检索形态为团队设计。

**O2 分级主动与"抑制"**
- **研究问题**：何时该主动出声、何时必须闭嘴？如何用量化机制（分级触发 + 打扰预算 + 场景禁言）替代"全靠唤醒词"？
- **成功判据**：定义 ≥4 级主动梯度（静默记录 → 视野角标 → 轻震动 → 语音询问 → 直接执行）；实现"骑车/开会/交谈"自动禁言；Demo 可视化"本次为何没打扰你"。
- **出处**：真痛点——千问官方亲口承认"对没充分理解的用户不具备主动服务条件"；分级方案为本团队提出。

**O3 带宽感知输出编排**（差异化创新点）
- **研究问题**：同一答案，如何按用户当前状态（走路/骑车/开会/独处）自动选 语音 / 字幕 / 图标 / 震动 / 不说，并把 LLM 输出强约束为"≤N 字 + ≤1 可执行动作"？
- **成功判据**：同一问题在 ≥3 种场景下呈现 ≥3 种不同形态；HUD 模拟器可一键切换演示。
- **出处**：【团队洞察·假设】——市场暂无明确需求喊声，是本项目跳出红海三场景的主要创新杠杆；对外材料标注为团队假设。

### 10.3 与红海三场景的绑定（不做替换，做加成）

| 原场景 | 叠加的研究目标 | 差异化叙事 |
|---|---|---|
| 实时翻译 | O3 + G9 置信度 | "归纳式翻译"而非逐句直译；不确定术语标注 |
| 视野导航 | O2 + G10 场景模式 | "你走错我才说"；骑行禁语音只震动 |
| 看物问答 | O1 + G2 办事闭环 | 这次问过下次主动关联；识别 → 比价 → 提醒 |

### 10.4 本期明确排除（避免摊大饼）

| 排除项 | 原因 |
|---|---|
| G5 端云路由 | 技术分高但 Demo 难呈现"走哪条路径"的观感价值有限 |
| G7 反向设备调度 | 需真实 IoT/车机，模拟器内无法可信演示 |
| G8 垂直人群 | 叙事强但超出"出行辅助"范围，易分散评委焦点 |
| G9 诚实度 | 降级为 O3 的附加层（置信度表达），不独立成目标 |
| G10 场景模式 | 降级为 O2 的底座能力（禁言判定输入），不独立成目标 |

> **聚焦理由**：初赛 8.16 截止，3 个目标均可在 HUD 模拟器内纯软件演示、且全部眼镜原生；比铺开 10 个更易在评审中出彩。
