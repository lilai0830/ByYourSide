### S4 市场格局：三条产品路线 `★★★`
- **页面标题**：智能眼镜已分化为三条路线，交互重心决定天花板
- **导语**：我们落在哪条路线？——C 路线的"轻量信息层"正是 Agent 的舞台。
- **正文内容**（三栏卡）：
  - **A · 音频眼镜**：代表 华为音频智能眼镜2 / Echo Frames；核心逻辑 蓝牙耳机塞镜腿 + 基础语音 AI；交互重心 语音 + 镜腿触控；天花板 眼镜形耳机，可替代性强
  - **B · 拍摄 AI 眼镜**：代表 Ray-Ban Meta Gen2 / 小米 / 华为 / Rokid Style；核心逻辑 第一视角记录 + 语音多模态问答；交互重心 语音 + 触控 + 快门键；天花板 出货主力 ~70%，"手机配件"定位难破
  - **C · AI+AR 显示眼镜**：代表 Meta Display / Rokid / 千问 S1 / 雷鸟 X3 / Even G2；核心逻辑 视野内轻量信息层 + 空间交互；交互重心 语音 + 触控 + 手势/腕带/眼动；天花板 寄望"下一代终端"，占比 ~29.8%
- **底部一句（行业原话）**：Meta"先做一副时尚社交眼镜，再加 AI"；Rokid/千问"先为 AI 设计一套系统，外形恰好长成眼镜"——前者争销量，后者争**交互标准与生态定义权** `【媒体】`
- **可视化元素**：三栏等宽卡，C 栏描边高亮；底部引号区。
- **讲稿要点**："我们选 C 路线的'轻量信息层'作为载体——它不是堆硬件，而是给 Agent 留出了'在视野里说话'的天然入口。"
- **备注**：本页不展开单品参数（参数放附录或口述），聚焦路线逻辑。

### S7 被忽视的输出侧空缺（差异化土壤） `★★★`
- **页面标题**：最窄的带宽，最被忽视的设计——这就是我们的切入点

- **正文内容**：

  - **同一问题 × 四种场景（示例"附近有地铁站吗？"）**：

    - 独处 → 完整语音播报
- **可视化元素**：左侧"最窄带宽"视觉（细管道）；右侧 2×2 四象限，每格放一种形态示意。
- **讲稿要点**："这就是 O3 带宽感知输出的来历——同一个答案，按你当下的状态自动选字幕/语音/图标/震动。这个 Demo 在模拟器上能直接可视化，是跳出红海三件套最直观的杠杆。" `【O3 = 团队创新假设，须标注】`

### S8 用户真实痛点地图（按层） `★★★`
- **页面标题**：痛点分层——硬件我们绕开，交互与智能层正是 Agent 机会
- **正文内容**（四象限/分层）：
  - **硬件层 · 绕开**：重量 36~51g 是普通镜 2 倍、续航官标 vs 实测差距大、端侧 90% 依赖云 `【机构/UGC】`
  - **交互层 · Agent 可改善**：唤醒慢、不支持连续对话、输出通道单一、反馈缺失、交互割裂 `【媒体/UGC】`
  - **智能层 · 核心机会**：视觉理解粗糙（问拿铁答"杯子"）、**无个人上下文**、场景理解"通用废话" `【媒体/UGC】`
  - **信任层 · 评分红线/差异化**：被摄者零知情权、无追溯机制、AI 从不说"我不确定" `【机构/媒体】`
